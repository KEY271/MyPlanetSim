# Phase 13 検証記録

状態: P13.01--P13.10 の実装・独立 column・全球比較・係数感度・1200日 pilot を実施。
数値的な pilot gate は完了した。model-top に達する深い対流と既存の全系エネルギー残差が
残るため、気候適合性または厳密な気候平衡は宣言しない。
本書の数値は Release build、AppleClang、2026-09-08--09 の実測値である。

## P13.01--P13.08 — 実装済み gate

[ADR 0019](../adr/0019-dilute-water-and-moist-physics-coupling.md) が dry-air mixing ratio、希薄液相水、
水・湿潤 enthalpy 台帳、分割順、bucket と海洋 reservoir、checkpoint schema を固定する。
unit test と `phase13.moist_cli` は、多成分輸送、非負性、飽和調節、蒸発・露、SBM、
rollback、restart の byte 一致、CSV schema と有限性を検証する。

`configs/phase13_moist_ci.cfg` は接続用の短い CI preset であり、気候実験ではない。
独立 column の時間・鉛直収束と診断については P13.08 のテストと
`tools/plot_moist_column.py` が担当する。

## P13.09 — 全球比較行列

標準ケースは N=6、K=20、地表細分化 S=5、灰色放射、bulk 境界層、即時飽和調節、
Simple Betts--Miller、aquaplanet である。model top は 20,000 Pa とした。
280 K の isothermal 初期場で従来の 1,000 Pa 上端を使うと、上層の飽和蒸気圧比が
希薄水の適用上限を超えるためである。この preset は対流圏下部の液相のみを対象とし、
上部対流圏・成層圏、雲、氷、降水再蒸発には適用しない。

再現コマンド:

```sh
cmake --preset release
cmake --build --preset release
python3 tools/compare_moist.py --suite one-day
python3 tools/compare_moist.py --suite thirty-day
python3 tools/collect_moist_results.py
```

各ケースは独立プロセスで実行する。派生 config、コマンド、stdout/stderr、日次 sample、
最終 3-D snapshot は `output/phase13-comparison/`、コミット対象の小さい数値集計は
`phase-13-results.json` に保存する。温度 RMS は cell 面積と層質量で重み付けする。

## P13.10 — 1200日 aquaplanet pilot

`configs/phase13_moist_pilot.cfg` は N=6、K=20、top=20,000 Pa、S=5、
dt=1800秒、半陰解法3反復、物理 substep=300秒、1200日の登録済み aquaplanet である。
リポジトリ root の foreground で次を実行した。

```sh
cmake --build --preset release
python3 tools/run_phase13_pilot.py
```

runner は既定で100日相当の accepted step ごとに同じ config fingerprint で再起動し、
`output/phase13_moist_pilot/pilot.chk` を更新する。各区間の CSV とログは
`output/phase13_moist_pilot/segments/segment-NNNN/` に保存する。
端末で Ctrl-C すると simulator に SIGINT を転送し、graceful checkpoint 後に停止する。
再開コマンドは次のとおり。

```sh
python3 tools/run_phase13_pilot.py --resume
```

12区間、57,600 accepted step で1200日を完走した。最初の11区間は100日ごとに停止・再開し、
最後の区間は `result.status=complete`。全区間の config fingerprint は
`0bd6d5bc3bb218e6` で一致する。restart 境界の大気水量、陸水量、累積蒸発・降水・海洋受け払い、
tracer 質量、乾燥質量の診断値は厳密に一致した。連続1200日 run との全 state byte 比較は行っていない。

wall time は合計52分13秒、`2.611 s/model-day`。受理 dt は全区間1800秒、物理 substep は
345,600回、CFL・invariant・solver・physics retry はすべて0だった。全CSVの約281万個の数値に
NaN/Inf はない。post-spinup の最低温度は `200.330 K`、最大風速は `51.341 m/s`。
乾燥質量の相対 drift は `2.58e-15`、受動 tracer 質量 drift は `1.06e-14`。
水蒸気 mixing ratio は `8.91e-6--0.02911` で非負かつ希薄上限0.1未満、
希薄上限超過面積は全区間で0だった。

### 平衡性と既知の全系エネルギー残差

200日除外後の最初の2 block は TOA が `-5.37/-1.94 W m-2` であり、200日は
spin-up 除外として短い。400--1200日の TOA は `+0.079 W m-2`、600--1200日は
`+0.267 W m-2`。地表面積平均温度は200日の `300.110 K` から1200日の
`301.567 K` へ上昇したが、最後の400日の100日端点は `301.468--301.822 K` に収まる。
水循環と地表温度は準定常に近づいたが、block 間変動が残るため厳密な平衡とは呼ばない。

200--1200日の `E_dry+E_latent+E_surface` は平均 `+0.9645 W m-2` の割合で増え、
TOA の正味下向き入力は `+0.6675 W m-2`。差の `+0.2971 W m-2` は既存の
全系エネルギー帰属で閉じない。600--1200日でも残差は `+0.3057 W m-2` と持続し、
同期間の TOA `+0.2669 W m-2`（上向き）と同程度である。放射 interface 残差、
地表時間積分残差、湿潤過程の moist enthalpy 残差は丸め誤差規模なので、これらの過程保存と
既存の力学・有限上端を含む全系残差を区別する。この pilot から気候エネルギー平衡は宣言しない。

### 対流・境界層と適用限界

200--1200日の面積時間平均は CAPE `218.4 J kg-1`、deep convection `0.7482`、
shallow convection `0.1347`、inactive `0.1171`。対流降水が全降水の97.1%を占める。
active column の平均 LCL は `93,969 Pa`、平均対流頂は `31,214 Pa` だった。

model-top 到達面積割合は平均 `0.6122`、各100日 block でも `0.591--0.623` で持続した。
top=20,000 Pa が深い対流を強く切っており、対流頂・上層構造を検証済みとはしない。
一方、境界層の平均高さは `863.6 m`、最大 `1087.9 m`、model-top 到達は0、
未解像浅層割合は平均 `9.95e-4`、最大 `0.0160`。境界層の規格化熱収支残差は
`<=1.91e-17`、運動エネルギー恒等式残差は `<=2.24e-14` だった。

最低温度が約200 Kであるのに雲・氷を含まず、飽和式も液相基準である。
したがって本結果は、top=20,000 Pa の bounded gray aquaplanet 上で希薄液相水循環の
数値結合を検証したものに限定する。実在地球の降水量、上層気候、雲・氷、放射平衡の
妥当性を示す結果ではない。Phase 13 はこの限定付き数値実装として完了とする。

### 集計器の既知の境界誤差

実行時の `pilot-summary.json` は `time_s >= 200日` と block の floor 分類により、
199--200日の区間を post-spinup に含めて1001日と数え、1200日点を余分な
1200--1300日 block に分類した。本節の値は raw CSV を `(200日, 1200日]` で再集計した
正しい1000日値である。集計器自体の修正は後続作業とし、この既知誤差を含む summary JSON を
検証根拠として単独では使用しない。
