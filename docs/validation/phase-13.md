## P13.09 — 全球比較行列

標準ケースは N=6、K=20、地表細分化 S=5、灰色放射、bulk 境界層、即時飽和調節、
Simple Betts--Miller、aquaplanet である。model top は 20,000 Pa とした。
280 K の isothermal 初期場で従来の 1,000 Pa 上端を使うと、上層の飽和蒸気圧比が
希薄水の適用上限を超えるためである。この preset は対流圏下部の液相のみを対象とし、
上部対流圏・成層圏、雲、氷、降水再蒸発には適用しない。

再現コマンド:

```sh
cmake --preset release
cmake --build --preset release
python3 tools/compare_moist.py --suite one-day
python3 tools/compare_moist.py --suite thirty-day
python3 tools/collect_moist_results.py
```

各ケースは独立プロセスで実行する。派生 config、コマンド、stdout/stderr、日次 sample、
最終 3-D snapshot は `output/phase13-comparison/`、コミット対象の小さい数値集計は
`phase-13-results.json` に保存する。温度 RMS は cell 面積と層質量で重み付けする。

### 時間刻み

1 日の dt=1800 秒・3反復と dt=450 秒・5反復の差は、温度 RMS `7.82e-4 K`、
PW `0.00198%`、E `0.0342%`、P `0.1496%`、TOA `0.227 W m-2` で、開始目標を満たす。
dt=30 秒 SSP-RK3 も完走し、半陰解法の短期基準とした。

30 日は次のとおり。P/E/TOA は全受理区間の積算量を実積算秒数で割った値である。

1800 秒・3反復は450秒基準に対し、全球平均温度 `0.086 K`、PW `0.17%`、
E `2.27%`、P `1.38%`、TOA `0.077 W m-2` の差で、retry は0。
一方、30日後の瞬時 3-D 温度 RMS は `1.553 K` で仮の `0.5 K` を超えた。
乱流場の瞬時一致を長期 gate にしないという計画に従い、この値は未達として残し、
統計量を満たした dt=1800 秒・3反復、物理 substep=300 秒を P13.10 候補に登録する。
再現性・瞬時場比較が必要な実験には dt=450 秒・5反復、substep=75 秒を使う。

| 乾燥 4成分 | 3.715 | 10.91 | 61 | 192 |

allocation はベンチマークの最初の受理 step 後から数えたプロセス全体の C++ allocation で、
column kernel 単体の workspace allocation だけではない。物理 substep を細かくすると
column 呼出しと allocation が比例して増える。1/2/4 成分で allocation 回数が同じなのは
workspace が成分配列をまとめて確保するためで、wall time と RSS は成分数とともに増える。

登録範囲は N=6、K=20、top=20,000 Pa、S=5 の bounded gray aquaplanet。
長期候補は dt=1800 秒・3反復・substep=300 秒、精細比較は
dt=450 秒・5反復・substep=75 秒。陸海・地形・同期回転は30日を超えて検証していない。
P13.10 では1200日を実行し、水 reservoir の傾向と block 統計を確認する必要がある。
